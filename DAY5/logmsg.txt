   what is log (which shows all the commits done)
  
 1.git log

 2.git log -n 2   ->(shows last 2 commits  n=number  i can 2 3 4 5 etc)

 3.git log --pretty=short
 4.git log --pretty=full    ---->(this commond gives detailed output of commit)

 5.git log -p       ---->(modified/chnages added in a commit)


 6.git log --pretty=format:"%h"   ->only gives hash codes of commits
    "%s"      ->gives commit message
    "%an"     ->give author name      
    "%ae"     ->gives author email id
                 git log --pretty=format: "%h %s %ae %an"


 7.git log --since="1 week ago"     ->give all one week commit
                                    --since="yesterday"    ->give alll yesterday commit
				    --since="1 month ago"  ->gives all one month commits
   git log --since="2026-05-23" --until="2026-06-23"      ->gives a range of commits from  a date


 8.git log --author="jatin"          ->gives commits of particular person or author


 9.git log --grep="modified"         ->searches and gives the commits with particular word
                                     ->used when i when i need modified files and bugs files
